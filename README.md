# Customer Churn Analysis Using Python

## Project Overview
This project analyzes customer churn patterns using the IBM Telco Customer Churn dataset. The goal is to identify customer characteristics associated with higher churn rates and develop data-driven recommendations to improve customer retention.

## Dataset
- **Records:** 7,043 customers
- **Features:** 21 columns
- **Target variable:** Churn

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis Performed
- Data exploration and quality checks
- Analysis of churn by contract type
- Customer tenure and monthly charge analysis
- Churn analysis by internet service and payment method
- Total charges analysis
- Data visualization and business recommendations

## Key Findings
- Overall churn rate was approximately **26.54%**.
- Month-to-month customers had a churn rate of **42.71%**.
- Electronic-check users had a churn rate of **45.29%**.
- Customers who churned had shorter average tenure than customers who stayed.

## Business Recommendations
- Improve retention among month-to-month customers.
- Investigate churn patterns among fiber optic customers.
- Strengthen onboarding and engagement for newer customers.
- Review billing experiences and payment patterns.
- Monitor churn using customer analytics dashboards.
